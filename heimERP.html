Erster Start: Klicke oben auf «Datenordner wählen» und wähle (oder erstelle) einen Ordner, z. B. C:\git\heimERP\Daten. Dort legt das Tool die Datei ausgaben.csv (mit Excel öffnenbar) und den Ordner Belege\<Jahr>\ für Rechnungen/Quittungen an. Funktioniert in Microsoft Edge und Google Chrome. Beim nächsten Start genügt ein Klick auf «Erneut verbinden».
